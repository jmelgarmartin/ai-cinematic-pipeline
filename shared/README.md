# shared

`shared/` contiene recursos reutilizables entre series. La idea es mantener aqui materiales comunes y evitar duplicarlos dentro de cada proyecto de serie.

Contenido previsto:

- `models`: documentacion y ubicacion local de modelos no versionados.
- `workflows`: workflows reutilizables, por ejemplo para ComfyUI u otros motores externos.
- `loras`: LoRAs compartidos entre series.
- `voices`: voces y referencias de voz compartidas.
- `music`: musica reutilizable o librerias internas.
- `sfx`: efectos de sonido.
- `templates`: plantillas de guion, metadata, prompts o configuracion.
- `prompts`: prompts base y variantes reutilizables.
- `scripts`: utilidades comunes.
- `overlays`: recursos visuales compartidos.
- `cache`: datos generados temporalmente.
