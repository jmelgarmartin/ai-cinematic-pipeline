# Modelos

Los modelos no se versionan en git. Esta carpeta sirve para documentar que modelos se usan y donde deben colocarse localmente cuando el pipeline los necesite.

Para cada modelo, documenta:

- Nombre del modelo.
- URL de origen.
- Version.
- Checksum, si existe.
- Requisitos de VRAM.
- Fecha de descarga.
